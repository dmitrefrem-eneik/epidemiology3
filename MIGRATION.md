# Стратегия миграции на Moodle (sdo.crie.ru)

Настоящий документ описывает процесс и структуру переноса базы знаний с текущего лендинга на платформу Moodle.

## 1. Сопоставление структуры данных

Текущая структура категорий лендинга напрямую транслируется в категории курсов или разделы в Moodle:

| Лендинг (категория) | Moodle (ресурс/элемент) | Примечание |
|---------------------|--------------------------|------------|
| Нормативная база    | Ресурс «Файл» / «Папка»  | Для PDF и официальных приказов |
| Учебно-методические | Элемент «Книга»          | Для структурированных программ и рекомендаций |
| Практика            | Элемент «Страница»       | Для инструкций и FAQ по практике |
| Стипендии           | Элемент «Глоссарий»      | Для терминов и быстрых справок по выплатам |
| Шаблоны             | Ресурс «Файл»            | Прямые ссылки на DOCX/XLSX шаблоны |
| Архив               | Скрытая категория        | Доступна только администраторам и менеджерам |

## 2. Метаданные и поиск

Метаданные из Frontmatter (markdown файлов) должны быть перенесены в соответствующие поля Moodle:

*   **Title** -> Название ресурса.
*   **Description** -> Описание (Вступление) ресурса.
*   **Category** -> Категория курса или тег.
*   **Date** -> Дата публикации в описании или настраиваемое поле.
*   **Tags** -> Система тегов Moodle (Tags).

## 3. Этапы миграции

1.  **Экспорт контента**: Markdown файлы конвертируются в HTML или напрямую вставляются в редакторы Moodle (Atto/TinyMCE).
2.  **Настройка ролей**: Перенос прав доступа (Администратор, Преподаватель, Обучающийся) на стандартные роли Moodle.
3.  **Интеграция поиска**: Использование глобального поиска Moodle или плагина поиска по метаданным.
4.  **Синхронизация с мессенджерами**: Настройка Moodle Notifications или внешнего бота через API Moodle для уведомлений в Telegram/Max.

## 4. Рекомендации по поддержке

*   Использовать плагин **FilterCodes** для красивого отображения метаданных.
*   Для версионности использовать расширение **Feedback** или историю правок в элементе «Wiki» (если требуется совместное редактирование).
*   Регулярно (раз в квартал) проводить аудит актуальности ссылок между Moodle и внешними системами (Teachbase).
