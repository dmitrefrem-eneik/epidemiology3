# Структура проекта Базы Знаний

Проект построен на стеке **SvelteKit + Tailwind CSS + mdsvex**. Ниже приведено описание ключевых директорий и файлов для понимания устройства системы.

## 📂 Папки и файлы

### `src/content/` (Главное хранилище контента)
Здесь хранятся все документы базы знаний в формате Markdown (`.md`).
- `normative/` — нормативно-правовые акты и локальные приказы.
- `academic/` — учебно-методические материалы.
- `practice/` — всё по практике и ГИА.
- `stipends/` — положения о стипендиях и финансах.
- `archive/` — архивные версии документов.

**Как добавить документ:** Просто создайте `.md` файл в нужной папке. В начале файла обязательно должен быть блок с метаданными (Frontmatter):
```markdown
---
title: Название документа
description: Краткое описание
date: 2026-01-01
category: normative
published: true
---
```

### `src/lib/` (Логика и компоненты)
- `components/` — визуальные элементы сайта (шапка, боковое меню, поиск).
- `kb.ts` — скрипт, который "сканирует" папку `content` и превращает файлы в страницы сайта.
- `utils.ts` — вспомогательные функции для стилей.

### `src/routes/` (Страницы сайта)
- `+page.svelte` — главная (лендинг).
- `kb/` — раздел базы знаний.
  - `+page.svelte` — список всех документов с фильтрами.
  - `[...slug]/` — динамическая страница для отображения текста конкретного документа.

### Конфигурация
- `svelte.config.js` — настройки SvelteKit (включен статический адаптер для GitHub Pages).
- `vite.config.ts` — настройки сборщика и плагина Tailwind CSS.
- `.github/workflows/deploy.yml` — сценарий для автоматического обновления сайта при пуше в ветку `main`.

## 🚀 Как работать с проектом

1. **Добавление контента**: Добавьте `.md` файл в `src/content/`.
2. **Локальный запуск**: `npm run dev`.
3. **Публикация**: После внесения изменений и пуша в GitHub, сайт обновится автоматически через GitHub Actions.
